Inverse Kinematics Test

2018

Project to learn Unreal Engine's inverse kinematics system and the required structure of the skeletal mesh used. The project is a simple scene with an octopus skeletal mesh. The tentacles are controlled by an IK chain, and can be moved with the mouse to grab various objects in the scene.

Model and skinning was done in Blender. Environment textures by Epic Games.
