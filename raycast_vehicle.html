C++ Raycast Vehicle for Unreal Engine

2020

An implementation of the raycast vehicle model using a custom C++ PawnMovementComponent.

The vehicle body uses a static mesh for collision and a skeletal mesh for the visual representation. The suspension is calculated by performing a raycast against the ground at each wheel and using the distance to apply a spring force. The skeletal mesh uses a modified AnimInstance similar to Epic's UE4 PhysX VehicleAnimInstance, and is mainly used to pass the wheel parameters to the animation blueprint.

Adjusting the handling of the vehicle is more complex compared to a kinematic model because of the number of physics parameters, so I used Unreal's UProperty reflection system to expose all of the actor and wheel properties during run-time. I also added a system that can draw a graph of any of the properties of the vehicle over time.

The reflection system also allows modifying and creating new vehicle types directly in the Editor.

Vehicle model by AnimPic Studio.
