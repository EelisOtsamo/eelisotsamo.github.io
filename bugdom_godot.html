Bugdom (1999) Godot Port

2023

Project I initially started to learn Godot's import plugin system by writing an importer for 3DMF (format used in the Mac OS QuickDraw 3D) models and textures used in the Mac game Bugdom by Pangea Software.

At first, I wrote a GDScript importer for the 3DMF based on the Pomme implementation of the Macintosh Toolbox C API used in the updated version of Bugdom

After learning how the 3DMF file format works, I rewrote the importer in C++ using the GDExtension system provided by Godot.

Using the level data from Bugdom, I wrote an import script that creates a Godot scene tree using the object positions and terrain data. I created prefab scenes for the different object types in the game and ported the original C game logic, collision data, and animated shaders to GDScript, which the level import script then places using the level data.

Challenges:

  • Figuring out the layout of texture pixel data in the 3DMF format was challenging, especially the terrain texture maps, since original game generates the terrain mesh and textures dynamically around the player depending on view distance.
  • Bugdom stores level data, such as terrain heightmaps and object positions, in a custom format, and the updated Bugdom version converted the files to make cross-platform porting easier. Instead of integrating the support for the converted files, I instead modified the Bugdom source to dump the level data I intended to use during runtime to a simple binary format, which I then import in the GDExtension.
