Root Motion Character Controller for Godot

2023

Learning project for the Godot game engine. I attempted to replicate the Controller + Character system Unreal Engine uses in Godot. The character is animated using an animation tree state machine, which can optionally be used to control the character using the root motion data from the animations.

Character head movement toward objects at the center of the screen is done using a 2D Blend Space.

Both the player and the NPC characters use the same movement system but with different controllers.

Uses textures from kenney.nl
