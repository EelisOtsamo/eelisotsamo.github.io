Vertex Color Tools

2023
Project Page on GitHub

Blender add-on for painting and editing vertex colors.

Blender provides a paint mode for vertex colors, but working on low-poly models with it is difficult. The add-on provides tools and operators for painting vertex colors directly on any individual mesh elements.

The add-on also includes tools for painting gradients in 3D space or along the mesh topology.

Challenges:

  • Learning Blender's internal BMesh structure and how it stores color attributes and topology information.
  • Achieving feature parity with the built-in color manipulation tools in Blender, which required porting some parts of Blender's C and GLSL code to Python, since they are not exposed to the API.
  • Learning the GPU module of Blender's Python API, which is used for drawing widgets in the 3D viewport using GLSL.
